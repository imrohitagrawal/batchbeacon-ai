I = integrator; B = backend builder; U = UI builder; E = evidence custodian/QA; R = independent reviewer; P = presenter/captain. **Actual capacity U03: Rohit is the sole available human; Codex is the primary executor/integrator on one machine.** These letters are responsibilities, not extra people. Historical effort bands are **S 0.25–0.75 person-hours; M 0.75–1.5; L 1.5–3**, totaling approximately **31–66 person-hours** including checks/packaging. They are risk context, not a Codex throughput forecast. The previous two-builder 18–28 elapsed-hour estimate is superseded. Use EXECUTION_POLICY’s setup, finite native-goal and resume sequence. Keep actual personal/run times only in ignored local configuration. T33–T36 add material effort beyond those historical totals. Reforecast from actual integrated progress; retain the fixed finalization reserve. Do not divide effort by agent-window count or waive gates to fit the clock.

Dependencies name tasks plus gates. A “start” dependency permits work against a frozen interface; “sign-off” dependencies must pass before marking that task complete. Partial checkpoints below never count as completion of their parent task. `AUTH-CLOUD`, `AUTH-SPEND`, `AUTH-PUBLIC`, `AUTH-REMOTE`, `UI-SELECTED`, `OWNER-VIDEO`, `OWNER-SUBMIT` are explicit gates, not implicit outcomes of a task. Local work may continue when an unrelated external gate is blocked. U01 satisfies `OWNER-VIDEO` for 160/230-second cuts; final export/form validation remains. U02 / `UI-SELECTED` is now satisfied by the [18 October concrete visual approval](../docs/evidence/M1-visual-approval.md); earlier A structure-only acceptance remains history. ## Close a task only with evidence

Record requirement/AC → task → actual code → test/eval IDs → run artifact → F1–F6/demo/claim. Each evidence file records UTC time, command, source revision/tree digest, environment, exact case IDs/denominator, versions, outcome/failures/assistance and artifact path. External tests include endpoint/revision and configured identity in an approved sanitized form. Credentials, raw private traces and hidden expected answers do not enter public Git.

Use `BLOCKED` only for an unmet dependency/authority; use `FAIL` for an executed failed assertion; use `NOT RUN` for unexecuted checks. Skipped/inapplicable work has an explicit reason. A task can be locally implemented yet have real-service evidence BLOCKED. No completion claim can outrun its weakest required gate.
