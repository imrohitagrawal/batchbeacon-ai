# Design documentation sidecar

`design.json` extends root `DESIGN.md` using Impeccable schema version 2.
The root frontmatter owns the approved primitives. Component snippets show the
existing control families with scoped, self-contained HTML/CSS and token fallbacks;
they are documentation examples, not application routes or a functional backend.

The eight-step OKLCH ramps are synthesized palette previews for the design panel.
They are not additional approved application colors. Application changes continue
to use the exact root tokens. No new palette, installation, engine command, hook,
network request or production integration is authorized by this sidecar.
