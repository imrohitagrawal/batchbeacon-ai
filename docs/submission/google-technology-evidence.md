## Why this Gemini version is relevant

The configured model is`gemini-3.8-flash`, model location`global`, with`LOW`thinking.
Current generation uses an ExtractionProposal JSON schema, text responses, disabled
automatic function calling/continuation and a single ADK model-call ceiling.
Image understanding and structured outputs are the relevant capabilities: the
model helps read the label and returns proposals the server can validate.

Google documents multimodal inputs, structured output, thinking controls and tool
capabilities for this model. The current application uses a narrow subset.
[Google Cloud model reference](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-8-flash),
[Gemini API model reference](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash).
These pages do not prove our data-analysis accuracy. Newer model capability is not
a substitute for reviewed source versions, exact identity/batch comparison,
protected evaluations or human decisions. No measured claim of better accuracy,
latency, cost or research thoroughness than another model is supported.

The current agent has no search tools and does not discover or update live recall
sources. It does not use the model's full context capacity, computer use, audio,
video, code execution, RAG or external search grounding. Mumbai app/data placement
plus a global model endpoint does not guarantee India-only model processing.
