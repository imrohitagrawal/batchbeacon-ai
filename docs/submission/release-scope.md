# Owner-approved hackathon demonstration scope

> This records the **U18 pre-submission scope decision** and its unresolved technical acceptance limitations. Final package approval and authenticated submission occurred subsequently under U21/U22; see [STATE](../STATE.md#final-submission). Later submission does not retroactively complete the technical gates listed here.

Explicitly approved by the owner under U18: “Approve this disclosed demonstration scope.”
This scope approval does not approve submission or mark unfinished internal
acceptance requirements as passed.

The candidate demonstrates a synthetic, historical SFA Singapore investigation:
photographed label → actual Gemini through one bounded ADK workflow → deterministic
identity-first comparison → explicit simulated hold → Firestore-backed owned queue.
Cloud Run hosts the app; source, image storage and technical Operations remain
separate from public guest capabilities. Independent public-access checks and a fresh unauthenticated real-model journey
passed; final artifacts and OWNER-SUBMIT remain open.

Verified private evidence includes session isolation and mutation guards,
observation-currentness invalidation, action deduplication, bounded model/guest
accounting, maximum-input backpressure recovery and fixed guidance evaluation
(six cases/nine variants), activation and rollback. The upload-recovery correction
has exact-head hosted evidence: 1,335 unit and 70 browser checks. Its deployed
acknowledgement-loss exercise uses a real upload with deliberately injected network
loss; retained bytes and original-key recovery are checked without another upload.
These engineering checks are separate from model-quality evaluation.

The approved narrower demonstration leaves these acceptance items incomplete:

- Live source ingestion/refresh and a deployed genuine source-update journey.
- The complete six-scenario deployed suite, including real uncertain-label recapture.
- The full 24-development/eight-protected model-quality evaluation and final-case
  custody. No accuracy percentage or protected evaluation pass is claimed.
- Complete Operations application telemetry, uptime-check and observed alert
  firing/closure acceptance, and observed physical image-cleanup acceptance.
  Configured lifecycle/soft-delete behavior is not proof of completed deletion.

UK FSA matching remains review-only under existing U17. The demonstrated sources
are selected historical notices, not a complete or continuously updated recall
service. Unknown, stale, unsupported or foreign-scope evidence cannot grant
clearance; the verifier, ownership checks and spending limits are unchanged.

Notice/PDF product-image extraction (ATT-01), the consumer dashboard and visual
catalogue retrieval (CON-01), and permissioned aggregate insights remain explicit
future scope. No real inventory action, safe-to-consume/sell claim, national
coverage, adoption or measured harm reduction is asserted.

U18 accepts these disclosed demonstration boundaries only. Security,
public access, artifact completeness, tested links, the official competition
requirements and final OWNER-SUBMIT/material-terms gates remain mandatory.
