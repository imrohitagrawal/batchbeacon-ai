## Capture prerequisites and review

- Capture the exact accepted candidate in a fresh guest. Preserve visible
  synthetic, historical, source-version and simulated-action labels.
- Use genuine runtime behavior for every functional claim. A prototype screenshot
  can illustrate design only when clearly labelled as such.
- Keep model extraction separate from deterministic rules and explicit human
  action. Never imply that a result automatically changes real stock.
- Exclude credentials, private dashboard URLs, account identifiers, personal
  operational timings and protected final-case answers. Show private operations
  through an approved sanitized recording, not by publishing its access link.
- Measure final exported duration, file properties, audio, readable text and
  playable public access. Preserve actual run/source/config/artifact provenance.
- Match the final deck, guide, description and repository revision. Final owner
  submission approval remains separate from the already-approved video lengths.
