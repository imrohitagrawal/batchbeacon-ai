### Exact local preparation sequence

The executor performs this sequence; the owner need not manually install each skill. These are future instructions requiring local verification, not commands run in this planning session.

1. Inspect existing `.agents/skills`, applicable configuration and the actual Git/client tools. Verify `.local/` is ignored and not tracked before using it as an optional private staging location.
2. Fetch the exact pinned source through the available authorized repository connector or Git into a new nonconflicting staging directory, without running installers, hooks or package lifecycle scripts. Verify the returned checkout/ref is exactly the selected SHA. Do not use mutable `latest` or copy a similarly named package.
3. Read the selected SKILL and every referenced file needed by the intended operation, the complete payload manifest, license/notice, scripts and nested configuration. If a generated distribution is chosen, verify that artifact's relationship to the same pin. A source pin is not an artifact checksum.
4. Prefer the full reviewed single-skill payload and license/notice in the actual supported project-local destination. Omit separate provider hook manifests by default. Do not silently strip required files while claiming an unmodified upstream installation; any adaptation gets its own diff/hash/provenance and compatibility check. If nested executable/automatic behavior cannot be bounded, retain explicitly labelled reference guidance or native fallback instead.
5. Record the exact platform-specific copy/install command **after** the staged source path, destination, payload and local shell have been verified; execute only the admitted scope. Compare copied hashes, inspect configuration diff, then verify discovery/loading in the real client. No global path, automatic hook approval or unreviewed paid network behavior is required for P0.
6. Invoke with a concrete target, inspect the generated/changed artifact and record the result. A bare Emil invocation may only greet readiness; give it the actual review task.
