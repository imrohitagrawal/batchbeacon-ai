# Readable evidence references

The expanded technical disclosure still rendered repeated identifiers, hashes and
image coordinates as one paragraph. Moving it into an accordion did not explain
the data. U47 explicitly authorizes implementing the proposed presentation.

The selected-field panel explains what the references represent, provides direct
links to matching saved images and the exact notice, then shows the existing field
values, rule and result. Counts derive from actual references; missing references
remain visible rather than receiving a fabricated link. The notice is bound to the
saved candidate dependency and source reference, not the mutable chooser; image
links require the owned retained capture ID and fingerprint.

Audit details use grouped source/label records with meaningful labels, full exact
IDs and fingerprints, user-triggered Copy controls and adjacent accessible feedback.
Clipboard denial/unavailability offers a selected read-only value for manual copy.
Delayed completion cannot update a changed or expired field. Exact locations remain
in a further disclosure, with an explanation that coordinates locate text rather
than express confidence. Every original reference and rule distinction is retained.

Independent plan reviews reproduced the raw presentation and two link-binding
defects. Regression checks cover expanded phone/desktop layout, actual local image
opening, source/capture mismatches, exact values/counts, unknown rules, clipboard
success/failure and detached/expired controls. Those use controlled backend/model
fixtures; they do not establish human usability or VoiceOver acceptance.

The scoped change touches three packaged UI assets. Backend, model configuration,
source corpus, runtime, accounting, ownership and original hero remain unchanged.
Exact local/hosted/package/release outcomes are recorded with the correction PR
and ignored `.local/run-records/evidence-audit-20261027/` checkpoint. Implementation
is not a claim of deployment. All R01–R12/F1–F8 and earlier failed/partial evidence
remain retained; human, protected source/quality and other disclosed gates stay open.
