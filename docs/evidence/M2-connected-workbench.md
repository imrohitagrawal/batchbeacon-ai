# Connected workbench — local integration checkpoint

The approved Evidence in focus layout now drives an explicitly injected owned
service graph. Archived prototypes are unchanged. The default preparation app
remains separate; this increment is not a deployed or real-model product claim.

The actual browser journey creates a guest and incident, uploads an approved
synthetic image, executes installed ADK through mock HTTP, reads deterministic
comparisons, prepares an action, requires explicit confirmation, saves it through
the Firestore SDK/fake RPC adapter, reloads, and reopens it from the owned queue.
A separate browser context cannot access the incident. All returned candidates
remain visible, identity precedes predicates, and scoped negatives offer no hold.
Corrections retain original values and require separately bounded deterministic
re-verification, which makes no model call. Queue refresh is manual and preserves
an explicitly historical snapshot after failure.
