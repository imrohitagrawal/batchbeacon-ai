# Render inspection

Modified from Impeccable craft-floor.md; see ../PROVENANCE.md and ../LICENSE.
Verify body contrast at least 4.5:1 and large text at least 3:1, purposeful
grouping, stronger separation between tasks, fixed type hierarchy and no overflow.
Use tabular numerals for compared data. Inspect real copy at desktop and phone
sizes. Keyboard focus must remain visible; touch targets must be usable.

Inspect hover, active, disabled, loading, empty, error and stale states together.
Use precise action labels and recovery guidance. Avoid repetitive cards, nested
cards, invented metrics, ornamental gradients, fake illustrations, excessive
shadows, emoji icons and accidental monospaced UI. Authored geometric SVG icons
are fine. Native scrolling is retained. Product Operate rules override decorative
motion and custom browser-surface suggestions. No automatic detector is implied.
