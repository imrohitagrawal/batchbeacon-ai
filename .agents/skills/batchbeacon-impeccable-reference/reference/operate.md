# Operational product guidance

Modified from Impeccable operate.md; see ../PROVENANCE.md and ../LICENSE.
Use a familiar shell and standard native controls. One sans family and a fixed
rem scale suit a dense application. Restrained surfaces, a quiet secondary plane
and semantic states make task hierarchy visible. Accent serves actions and
selection. Tables may be dense; prose remains readable.

Responsive changes are structural: collapse navigation, stack work areas and
make each evidence row readable on a phone. Keep default, hover, focus, active,
disabled, loading, empty and error states consistent. Errors name recovery.
Use native dialog/popover when needed to escape clipping; prefer inline work.
Motion communicates state only, typically 150–250ms, and never delays frequent
actions. No choreographed entry, display faces in controls or decorative motion.
